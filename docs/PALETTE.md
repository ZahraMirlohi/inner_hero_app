# پالت رنگی برنامه

رنگ اصلی (`primaryColor`) را کاربر انتخاب می‌کند و فقط برای **دکمهٔ اصلی، حالت انتخاب‌شده و نوار پایین** است.
برای همهٔ جاهای دیگر از ۸ «تُن» پاستلی ثابت استفاده می‌شود: `theme.tone(Tone.x)` ← `bg` (ملایم) و `fg` (پررنگ‌تر).
در حالت شب خودکار تیره می‌شوند.

| تن | رنگ | کاربرد |
|---|---|---|
| lilac | بنفش ملایم | ظاهر و شخصیت، تحلیل‌ها، مربی هوش مصنوعی |
| sky | آبی آسمانی | زبان، چت، گروه‌ها، تقویم |
| peach | هلویی | استریک، یادآوری و اعلان، آتش و انرژی |
| butter | کرم زرد | امتیاز XP، افتخارات، چالش‌ها، هدیه |
| mint | سبز نعنایی | موفقیت، سلامتی، حریم خصوصی، عادت انجام‌شده |
| rose | صورتی ملایم | خروج و حذف (هشدار)، قلب و علاقه‌مندی |
| lime | سبز لیمویی | درباره، اکسپلور، بسته‌ها |
| apricot | نارنجی ملایم | رنگ برنامه، ماموریت‌ها، تایمر |

قواعد: هر کارت/بخش یک تن دارد؛ سطرهای داخلش می‌توانند از تن‌های همسایه استفاده کنند؛ هیچ‌وقت همهٔ آیکون‌های یک صفحه یک رنگ نباشند.
